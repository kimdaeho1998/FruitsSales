# 과일 시즌 커머스 웹서비스 화면/라우팅 명세서

## 1. 문서 개요

### 목적

본 문서는 **과일 시즌 커머스 웹서비스**의 화면(UI) 구성과 URL 라우팅
구조를 정의한다.

기준 플랫폼은 **Mobile First Responsive Web (Next.js App Router)** 이며,
고객 서비스(Customer)와 관리자 서비스(Admin)의 화면 구조를 모두
포함한다.

### 화면 구성 원칙

-   Mobile First UI 설계
-   Next.js App Router 기준
-   고객/관리자 영역 분리
-   시즌(복숭아·곶감) 중심 구조
-   비회원 주문 기준

# 11. 완료 기준

MVP 화면은 다음 조건을 만족해야 한다.

-   모든 고객 화면이 모바일 기준으로 구현된다.
-   모든 화면이 반응형으로 동작한다.
-   상품 상세에서 옵션 선택과 구매 CTA가 제공된다.
-   주문·결제 플로우가 연결된다.
-   비회원 주문 조회 화면이 제공된다.
-   관리자 화면에서 시즌, 상품, 주문, 배송을 관리할 수 있다.
